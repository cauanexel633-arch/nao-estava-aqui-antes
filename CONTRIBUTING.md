# Como contribuir / Contributing

## 🇧🇷 Português
Obrigado pelo interesse em ajudar **Não estava aqui antes**.

- Use a aba **Issues** para relatar bugs e sugerir melhorias.
- Pesquise se já existe um relato semelhante antes de abrir outro.
- Descreva o problema com clareza e inclua passos para reproduzi-lo.
- Não envie dados pessoais, senhas ou arquivos confidenciais.
- Este repositório é destinado à apresentação, distribuição e acompanhamento da DEMO. Combine previamente qualquer contribuição de código.

## 🇺🇸 English
Thanks for helping **Não estava aqui antes**.

- Use **Issues** to report bugs and suggest improvements.
- Search for an existing report before opening a duplicate.
- Describe the issue clearly and include reproduction steps.
- Never share personal data, passwords, or confidential files.
- This repository is intended for the DEMO presentation, distribution, and issue tracking. Please discuss code contributions before submitting them.
