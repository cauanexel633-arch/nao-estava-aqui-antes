# Segurança / Security

## Português
Não publique senhas, tokens, chaves privadas, dados pessoais ou informações sensíveis em Issues. Para problemas de segurança que possam afetar usuários, evite publicar detalhes exploráveis em um relato público; procure um canal privado de contato do mantenedor.

## English
Do not post passwords, tokens, private keys, personal data, or sensitive information in Issues. For security vulnerabilities that could affect users, avoid publishing exploitable details in a public issue; contact the maintainer through a private channel.
